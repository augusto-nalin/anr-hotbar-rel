# ANR's Hotbar Switcher (anr-hotbar)

A Cmd+Tab style hotbar switcher for Minecraft 1.21.1 (NeoForge): hold a modifier, a big hotbar
pops up over the game (with inventory rows below it), the pointer's column picks the slot, let
go to select. The world keeps running and you keep moving.

Works on its own (modifier + click, its own key, the mouse wheel). With
[ANR's Trackpad & Touchpad Tweaks](https://github.com/augusto-nalin/anr-trackpad-rel) it also
opens with Cmd + a two-finger swipe, a deep press or a Magic Mouse tap, and its settings show
on that mod's settings screen.

## Requirements
- Minecraft 1.21.1, NeoForge 21.1+

## Reporting a bug
Open an [issue](../../issues/new/choose) with your Minecraft / NeoForge / anr-hotbar versions,
steps to reproduce, and your `logs/latest.log`.

## About this repository
This repository hosts the issue tracker and `update.json`, which the update checker reads
to show "update available" in the Mods list. The mod's source is not published here.
